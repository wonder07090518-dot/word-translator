# 单词小标

一个 macOS 菜单栏小工具：鼠标停在屏幕上的英文单词时，自动识别，并在单词旁显示最多四个常用中文意思。

## 使用

1. 双击 `单词小标.app`。
2. 第一次运行时，允许“屏幕与系统音频录制”。这是读取屏幕文字所必需的权限；应用不会保存截图。
3. 第一次翻译时，允许 macOS 下载英语和简体中文翻译语言；翻译会在设备上完成。
4. 把鼠标停在一个英文单词上大约半秒，小标会出现在单词旁边；鼠标移开后自动隐藏。

菜单栏的书本图标可以暂停识别、隐藏浮窗，或显示权限提示。

## 构建

在此文件夹打开终端，运行：

```sh
./build-app.sh
```

应用会生成在 `dist/单词小标.app`。

应用使用 Apple 的 Vision、ScreenCaptureKit 和 Translation 框架，不需要第三方翻译密钥。OCR 和翻译都由系统完成。
